Full-Stack Web Application

MSRTC – Diesel Management System

MSRTC depots traditionally keep diesel records and bus trip details in paper registers. This system reduces that paperwork, improves data accuracy, and gives depots centralized tracking and analysis of bus operations.

  • Next.js
  • React.js
  • TypeScript
  • Supabase
  • PostgreSQL
  • Tailwind CSS
  • Lucide React

Screenshots

Key features

Dashboard

Operational statistics, daily diesel and vehicle summaries, and a quick overview of depot activity.

Live vehicle management

Add trip entries with bus number and employee details, record the start time, track active trips and close them when the vehicle returns to the depot.

Employee management

Store driver and conductor information and badge numbers, and view each employee’s vehicle and trip history.

Bus analytics

Bus-wise trip records, kilometres travelled, and the performance and history of each bus.

Diesel management

Manage diesel records and track consumption with related operational information.

Reports & analytics

Analyze daily operational data and generate summaries that support better decisions.

Account & security

Role-based access for Admin, Officer and Clerk, with secure authentication and database access.
